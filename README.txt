FAMILY OFFICE NUNEZ - INSTALACION

1. Esta app es una PWA y debe servirse desde una dirección web segura (HTTPS) o desde localhost.
2. La forma más sencilla es publicar la carpeta en GitHub Pages, Netlify, Cloudflare Pages o un servidor interno.
3. Abre la URL con Chrome en Android y elige "Añadir a pantalla de inicio" o pulsa "Instalar app".
4. Los datos se guardan en IndexedDB dentro del navegador del móvil.
5. Exporta periódicamente la copia JSON. Si se borran los datos del navegador o se cambia de móvil sin copia, se perderán.
6. El Markdown del último mes está pensado para subirlo a ChatGPT y generar el informe mensual.

IMPORTANTE: abrir index.html directamente desde el gestor de archivos puede mostrar la interfaz, pero el modo sin conexión y la instalación PWA requieren HTTPS o localhost.
